# Retro Game 100% Completion Fix & Mod

Was frustrated as a kid with this game because **3 items were completely unobtainable**. I fixed it, so now both you and I can finally complete this game to **100%**!

## 🛠️ The Fix
The previously missing items can now be acquired as follows:
* **Iron Pike** – Can be bought from the shop in missions 8 and 9.
* **Templar** – Guaranteed loot from mission 10; can also be bought from the shop in missions 11 and 12.
* **Joker** – Can be bought from the shop after completing the game (e.g., after mission 12).

---

## 🚀 How to Play
To run the game, you need to open the `.swf` file in a standalone **Adobe Flash Player** (such as [this one](https://github.com/itsHenry35/Adobe-flash-player-installer)).

1. Open `flashplayer_sa.exe`.
2. Drag and drop the `.swf` file from the **Vanilla_Fixed** folder into the player.
3. Enjoy and play! **:)**
